# Multi-hop synthesis

Many questions cannot be answered from one article. Work them in steps.

1. **Decompose.** Identify the distinct facts the question needs — an
   entity from one article, a date or figure from another, a comparison
   across both.
2. **Retrieve each fact.** Run a separate search per sub-question instead
   of hoping one query surfaces everything. Vary phrasing: entity names,
   outlet names, event dates.
3. **Reconcile.** When articles disagree, prefer the one the question
   names; otherwise the more recent publication date, and say which you
   used.
4. **Answer the actual question first.** For a comparison, state the
   verdict (which, who, whether) before the supporting facts. For a
   temporal question, establish the timeline before drawing a conclusion.

Do not force a single retrieved article to answer a multi-article
question. If a needed fact is missing after real searching, treat the
question as out of scope rather than bridging the gap with general
knowledge.
